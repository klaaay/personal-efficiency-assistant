# Yuki 角色头像

角色选择：长门有希。头像通过当前平台内置 imagegen 工具生成，为 Yuki 阅读助手制作独立视觉资源；没有复制 ChatGPT Summarize 的图标或品牌素材。

## 生成提示词

以长门有希为角色方向，绘制原创日系动画头像：短紫灰色头发、琥珀色眼睛、细框眼镜，安静地抱着一本书。人物头像约占画面 75%，构图简洁，脸部与眼镜轮廓清晰，适合浏览器扩展的小尺寸图标。人物背后为淡紫色圆形底，圆形以外透明。不要文字、字母、标志或水印。

## 文件

| 文件 | 用途 |
| --- | --- |
| `yuki-master.png` | 生成头像的 master，作为缩放和后续调整依据 |
| `icon-16.png` | 16 × 16，浏览器小图标 |
| `icon-32.png` | 32 × 32，高密度工具栏图标 |
| `icon-48.png` | 48 × 48，扩展管理界面图标 |
| `icon-128.png` | 128 × 128，扩展大图标 |

manifest 的 `icons` 与 `action.default_icon` 使用这些 PNG。缩小后应保留清楚的脸部、眼镜与书本轮廓，不增加细碎背景或文字。
