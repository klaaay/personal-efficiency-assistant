## 2026-11-08：YouTube、阅读偏好与主备切换

### YouTube 实测与修复

真实 YouTube 公开字幕接口可能返回 HTTP 200 但正文为空；新版页面使用 `transcript-segment-view-model`，原实现只读取 `ytd-transcript-segment-renderer`。修复兼容两种节点，分别读取正文和时间戳，避免混入屏幕阅读器的重复时间标签；接口不可用时尝试页面文字稿入口，最多等待 8 秒加载，不读取评论代替字幕。

通过 HTTP 代理 `127.0.0.1:7897` 在独立 Chromium 中打开 [Steve Jobs' 2005 Stanford Commencement Address](https://www.youtube.com/watch?v=UF8uR6Z6KLc)。直接点击阅读按钮后自动展开并读取 110 条真实文字稿，共 12,935 个 Unicode 字符，包含开头和结尾内容。

模型响应由本地测试服务提供，用于核对真实字幕提取和实际发送材料，不据此评价真实模型的总结质量。修复前截图位于 `.local/verification/yuki-preferences`；修复后截图与结果位于 `.local/verification/yuki-youtube-fix`。

### 阅读偏好与回归范围

- 构建通过，36 项核心 / 迁移测试、27 项原有浏览器场景、10 项 YouTube 回归和 8 项阅读偏好 / 真实 YouTube 场景通过。
- 两种阅读按钮均验证保存、重载、出现和移除；关闭按钮时不触发模型请求，按钮可在保存后随配置变化，无需刷新网页。
- 开启全文处理时，实际请求包含尾段内容；关闭时仅发送第一段，并提示未覆盖全文。
- YouTube 回归覆盖新旧文字稿、时间戳、空响应 / 无效 JSON / HTTP / 网络错误后的回退、折叠描述展开、视频 ID 与来源检查，以及没有可用字幕时明确失败。
- 浏览器测试使用隔离用户目录和临时权限，不修改用户 Chrome，不覆盖原生授权弹窗。

### 主备切换优化

主接口首次有效输出预算缩短为 8 秒，连接、响应头和首段内容共用预算，心跳与空增量不能延长等待。已有进展后的生成停顿、备用接口及未配置备用的首次响应仍保留 30 秒。同一次长文切换后，后续分段与归并复用备用接口，下一次总结重新尝试主接口。

本地模拟服务验收了持续心跳超时、关闭故障连接、手动停止不回退和长文复用备用。从点击总结到备用回答完成，心跳场景实测约 8.4 秒；此次故障模拟没有调用真实模型服务。
